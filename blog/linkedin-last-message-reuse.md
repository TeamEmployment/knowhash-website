I hate writing the same message twice. So knowhash now remembers the last one for you.

Send an invite or a message the way you normally do. Next time, click into an empty compose box and press \ — your last one drops in, ready to read and send.

Sent a template as it was? It comes back as a template, so it fills in for whoever you're looking at next.

Changed it, or wrote it from scratch? It comes back exactly as you wrote it. One click on Create Template keeps it, with names and companies turned into pills for the next person.

→ Last invite and last message, one keystroke away (\)
→ Prefer a button? Fill is on the panel
→ Create Template turns a message that worked into a template
→ You still read it and press Send. knowhash never sends anything for you

It's in knowhash (free) and knowhash Recruit. Chrome updates it automatically.
