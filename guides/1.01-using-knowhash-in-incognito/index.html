Guide 1.01

Using knowhash in an Incognito window

Chrome switches extensions off in Incognito by default. If you open LinkedIn in an Incognito window and knowhash doesn't appear, you just need to allow it there.

Turn it on for Incognito

  1. In a normal Chrome window, type chrome://extensions into the address bar and press Enter.
  2. Find the knowhash extension you use (knowhash Recruit or knowhash) and click Details.
  3. Scroll down and switch on Allow in Incognito.
    Allow in IncognitoChrome can't prevent extensions from recording your browsing history.

    Chrome shows this standard warning for every extension. knowhash only works on LinkedIn pages.

  4. Close any Incognito windows you already have open, then open a new one with Ctrl+Shift+N (Windows) or ⌘+Shift+N (Mac).
  5. Sign in to LinkedIn. Incognito doesn't share your normal LinkedIn login, so you'll need to sign in each time you open a new Incognito window.
Only switch on one knowhash extension. If you have both knowhash and knowhash Recruit installed, allow just the one you use. Running both at once causes errors. See Guide 1.02: Use one knowhash extension at a time.

Still not showing?

Reload the LinkedIn page with Ctrl+Shift+R (or ⌘+Shift+R on Mac). If that doesn't fix it, email feedback@knowhash.com with a screenshot.
