Guide 1.02

Use one knowhash extension at a time

knowhash and knowhash Recruit both work inside LinkedIn. If both are switched on, they get in each other's way, and you may see messages like “Couldn't load” or panels that don't respond.

Which one to keep

knowhash Recruit already includes everything in the free knowhash extension: templates, your details, and last-message recall. It also adds the recruiting features. If you have Recruit, keep Recruit on and switch the free one off.

knowhash RecruitKeep this one on
knowhashSwitched off

How it should look on your extensions page.

Switch one off

  1. Type chrome://extensions into the address bar and press Enter.
  2. Find the knowhash extension you're not using and click its toggle so it turns grey.
  3. Go back to LinkedIn and reload the page with Ctrl+Shift+R (or ⌘+Shift+R on Mac).
Switch it off rather than removing it. Removing an extension deletes the templates you saved in it. Switching it off keeps them, so you can switch it back on later if you need them.

Using Incognito?

The same rule applies there. Only allow one knowhash extension in Incognito. See Guide 1.01: Using knowhash in an Incognito window.
